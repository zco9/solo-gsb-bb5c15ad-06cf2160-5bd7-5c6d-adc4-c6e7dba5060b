说明

批注只保存在本浏览器的 IndexedDB（不上传、不调用任何写接口、不连接 WebSocket），用于圈定同一已结束场次中的一段时间并记录批注与标签。 区间首尾以事件指纹锚定（事件 canonical JSON 的 SHA-256 + 该指纹出现序号）；重新载入日志时自动重新定位， 找不到指纹或终点顺序倒置则标为失效，原文完整保留。支持 JSON 导入 / 导出：按批注 id 合并，内容一致自动去重， 同 id 内容不同则两份均保留并明确标记冲突。在 演出复盘 播放位置可直接圈定区间进入本页。

④ 复盘播放清单（仅本浏览器 IndexedDB）

从下方有效批注勾选区间加入清单，拖拽行（或用 ↑ / ↓）调整播放顺序。清单只保存在本浏览器的 IndexedDB （独立库 cue-playlists，不上传、不连接 WebSocket）。 打开播放页后按清单顺序连续回放并自动跨场次切换：各段拼接为一条虚拟时间轴，拖动、播放与 1×/2×/4× 倍速 都按累计区间时长映射回对应场次的原始时刻，恰好落在边界时进入后一段。播放前会重新定位每条批注， 失效或日志缺失的条目自动跳过并集中列明原因；重叠区间按清单顺序分别播放，绝不合并。
